# Snow Courier

Original minimal three-map RPG authored in the Omasprite scene format. Open this project folder in WORLD, or run `cargo run -- --play examples/snow-courier`. Arrow keys move; Enter talks and advances pages. Deliver the message by reaching the gold marker on the eastern path. The northwest portal enters the lodge; its southern portal returns to town. Game Save/Load persists progress in saves/game.json.

The included four-frame player sprite is original procedural pixel artwork, editable in SPRITE. Scenery currently uses engine placeholder blocks. This is a functional fixture, not reference-quality finished artwork.
