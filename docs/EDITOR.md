# Editor workflow

1. Open WORLD and expand **Project · New / Open / Save**.
2. Enter a new folder path and a project name. The parent must exist.
3. If the active document is unsaved, save it first or explicitly check **Discard unsaved edits when creating/opening**.
4. Click **New project**. Paint terrain with the World toolbar and configure the NPC line/daylight.
5. Click **Save project** or the top **SAVE SCENE** button. Both save the active project scene.
6. Close/reopen the app, enter the project folder, and use **Open project**. The map, elevations, spawn, NPC and dialogue are restored.

Loose scene files remain supported when no project is open. PLAY enters the existing single-map runtime. Other editor workspaces are unfinished previews; their controls do not establish complete sprite, animation, lighting or scripting support.
